# Product Inventory API

REST API built with Express.js to manage a product inventory: products, stock movements, categories and suppliers.

Group 3 final project – BeTechified.

> **Note:** data is stored in memory. Every restart of the server resets it to the sample data.

## Tech stack

- [Node.js](https://nodejs.org/) 18 or later
- [Express 5](https://expressjs.com/)
- [dotenv](https://github.com/motdotla/dotenv): loads environment variables from a `.env` file
- [nodemon](https://nodemon.io/): restarts the server on file changes (development only)

## Getting started

```bash
git clone https://github.com/Ev-g127/Product-Inventory--API.git
cd Product-Inventory--API
npm install
```

Optional: create a `.env` file at the root of the project to choose the port (default: `3000`).

```
PORT=3000
```

Start the server:

| Command | What it does |
|---|---|
| `npm run dev` | Starts the server with nodemon, which restarts it on every file change |
| `npm start` | Starts the server with Node (use this in production) |

The API is then available at `http://localhost:3000`.

## Data model

**Product**

| Field | Type | Notes |
|---|---|---|
| `id` | number | Generated by the API, never reused |
| `sku` | string | Unique (ignoring upper/lower case), used in the URLs, cannot be changed |
| `name` | string | |
| `price` | number | Greater than or equal to 0, with 2 decimals at most |
| `category` | string | Name of an existing category |
| `supplier` | string | Name of an existing supplier |
| `quantity` | number | Units in stock: whole number, `0` by default. Set at creation, then only changed by stock movements |
| `lowStockThreshold` | number | Whole number, `5` by default. The stock is low when `quantity` is lower than or equal to it |

**Stock movement**

| Field | Type | Notes |
|---|---|---|
| `id` | number | Generated by the API, never reused |
| `productId` | number | `id` of the product |
| `type` | string | `in` (units added) or `out` (units removed) |
| `quantity` | number | Whole number greater than 0 |
| `reason` | string | For example `Delivery` or `Sale` |
| `stockAfter` | number | Units in stock after the movement, calculated by the API |
| `date` | string | Date and time of the movement (ISO 8601), set by the API |

**Category**

| Field | Type | Notes |
|---|---|---|
| `id` | number | Generated by the API, never reused |
| `name` | string | Unique (ignoring upper/lower case), used in the URLs |
| `description` | string | |

**Supplier**

| Field | Type | Notes |
|---|---|---|
| `id` | number | Generated by the API, never reused |
| `name` | string | Unique (ignoring upper/lower case), used in the URLs |
| `contact` | string | Name of the contact person |
| `email` | string | Must be a valid email address |
| `phone` | string | |
| `address` | string | |

At startup, the API contains 4 sample categories (`Category 1` to `Category 4`), 4 suppliers (`Supplier 1` to `Supplier 4`) and 4 products (SKUs `Product 1` to `Product 4`, with 20, 5, 0 and 50 units in stock and a low stock threshold of 5). The history of stock movements is empty.

## Endpoints

- Request bodies are JSON: send the header `Content-Type: application/json`.
- SKUs and names in URLs are case-sensitive and must be URL-encoded: `Category 1` becomes `Category%201`.

### Products

| Method | Path | Description | Success |
|---|---|---|---|
| `GET` | `/products` | List all products | `200` |
| `GET` | `/products?name=text` | List the products whose name contains `text` (case-insensitive) | `200` |
| `GET` | `/products/:sku` | Get one product | `200` |
| `POST` | `/products` | Create a product. Body: `sku`, `name`, `price`, `category`, `supplier` (required), `quantity` and `lowStockThreshold` (optional) | `201` |
| `PATCH` | `/products/:sku` | Update a product. Body: any of `name`, `price`, `category`, `supplier`, `lowStockThreshold`. Fields not sent are left unchanged | `200` |
| `DELETE` | `/products/:sku` | Delete a product | `200` |

### Stock movements

| Method | Path | Description | Success |
|---|---|---|---|
| `GET` | `/products/:sku/movements` | List the stock movements of a product, from the oldest to the newest | `200` |
| `POST` | `/products/:sku/movements` | Add units to the stock of a product (`in`) or remove some (`out`). Body: `type`, `quantity`, `reason` (all required) | `201` |

### Categories

| Method | Path | Description | Success |
|---|---|---|---|
| `GET` | `/categories` | List all categories | `200` |
| `GET` | `/categories/:name` | Get one category | `200` |
| `GET` | `/categories/:name/products` | List the products of a category | `200` |
| `POST` | `/categories` | Create a category. Body: `name`, `description` (all required) | `201` |
| `PATCH` | `/categories/:name` | Update a category. Body: `newName` and/or `description`. Fields not sent are left unchanged | `200` |
| `DELETE` | `/categories/:name` | Delete a category | `200` |

### Suppliers

| Method | Path | Description | Success |
|---|---|---|---|
| `GET` | `/suppliers` | List all suppliers | `200` |
| `GET` | `/suppliers/:name` | Get one supplier | `200` |
| `GET` | `/suppliers/:name/products` | List the products of a supplier | `200` |
| `POST` | `/suppliers` | Create a supplier. Body: `name`, `contact`, `email`, `phone`, `address` (all required) | `201` |
| `PATCH` | `/suppliers/:name` | Update a supplier. Body: any of `newName`, `contact`, `email`, `phone`, `address`. Fields not sent are left unchanged | `200` |
| `DELETE` | `/suppliers/:name` | Delete a supplier | `200` |

### Business rules

- A product's `category` and `supplier` must already exist.
- SKUs, category names and supplier names must be unique, ignoring upper/lower case (`Food` and `food` are the same name).
- Spaces at the start and end of SKUs, of movement reasons and of product, category and supplier names are removed (`" Food "` is saved as `Food`).
- The SKU of a product never changes: `PATCH /products/:sku` rejects `sku`.
- The quantity of a product only changes through stock movements: `PATCH /products/:sku` rejects `quantity`.
- A stock movement cannot remove more units than the product has in stock.
- Stock movements cannot be changed or deleted. To correct a mistake, create the opposite movement.
- A new product that uses the SKU of a deleted product starts with an empty history.
- Renaming a category or a supplier also updates the products that use it.
- A category or a supplier cannot be deleted while products still use it.

## Examples

**Create a product**

```http
POST /products
Content-Type: application/json

{ "sku": "SKU-100", "name": "Wireless Mouse", "price": 19.99, "category": "Category 1", "supplier": "Supplier 1" }
```

Response `201 Created`:

```json
{ "id": 5, "sku": "SKU-100", "name": "Wireless Mouse", "price": 19.99, "category": "Category 1", "supplier": "Supplier 1", "quantity": 0, "lowStockThreshold": 5 }
```

**Update only the price of a product**

```http
PATCH /products/Product%201
Content-Type: application/json

{ "price": 12.5 }
```

Response `200 OK`:

```json
{ "id": 1, "sku": "Product 1", "name": "Product One", "price": 12.5, "category": "Category 1", "supplier": "Supplier 1", "quantity": 20, "lowStockThreshold": 5 }
```

**Add units to the stock of a product**

```http
POST /products/Product%201/movements
Content-Type: application/json

{ "type": "in", "quantity": 10, "reason": "Delivery" }
```

Response `201 Created`:

```json
{ "id": 1, "productId": 1, "type": "in", "quantity": 10, "reason": "Delivery", "stockAfter": 30, "date": "2026-11-25T15:21:52.223Z" }
```

**Remove more units than available**

```http
POST /products/Product%203/movements
Content-Type: application/json

{ "type": "out", "quantity": 1, "reason": "Sale" }
```

Response `409 Conflict`:

```json
{ "error": "Not enough stock: only 0 available" }
```

**Search products by name**

```http
GET /products?name=two
```

Response `200 OK`:

```json
[{ "id": 2, "sku": "Product 2", "name": "Product Two", "price": 15.99, "category": "Category 2", "supplier": "Supplier 2", "quantity": 5, "lowStockThreshold": 5 }]
```

**Create a supplier**

```http
POST /suppliers
Content-Type: application/json

{ "name": "Acme", "contact": "Jane Doe", "email": "jane@acme.com", "phone": "+1 555 0199", "address": "10 Acme Road" }
```

Response `201 Created`:

```json
{ "message": "Supplier created successfully", "supplier": { "id": 5, "name": "Acme", "contact": "Jane Doe", "email": "jane@acme.com", "phone": "+1 555 0199", "address": "10 Acme Road" } }
```

## Errors

Every error is returned as JSON:

```json
{ "error": "Product not found" }
```

| Status | When |
|---|---|
| `400 Bad Request` | Missing field, wrong type, empty text, invalid email, invalid price, quantity, low stock threshold or movement type, nothing to update, `sku` or `quantity` sent to `PATCH /products/:sku`, unknown category or supplier, malformed JSON, badly encoded URL |
| `404 Not Found` | The product, category, supplier or route does not exist |
| `409 Conflict` | The SKU or name is already used, there is not enough stock, or a deletion is blocked because products still use the category or supplier |
| `500 Internal Server Error` | Unexpected server error (details are only written in the server logs) |
